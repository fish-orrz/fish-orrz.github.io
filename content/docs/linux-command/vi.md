文字編輯器。分「一般模式」與「編輯模式」，開啟檔案時是一般模式，無法直接輸入文字。

## 指令總覽

```text
i            進入編輯模式
Esc          回到一般模式
:wq          存檔並離開
:q!          不存檔強制離開
:set nu      顯示行號
/keyword     搜尋
:%s/old/new/g  全文取代
:1           跳到第一行
G            跳到最後一行
```

## 編輯與存檔

| 操作 | 說明 |
|---|---|
| `i` | 進入編輯模式，可開始輸入文字 |
| `Esc` | 回到一般模式 |
| `:wq` | 存檔並離開 |
| `:q!` | 不存檔強制離開 |

指令都是在一般模式輸入，以 `:` 開頭的按 Enter 執行。

## 顯示行號

```text
:set nu
```

## 移動

| 操作 | 說明 |
|---|---|
| `:1` 或 `gg` | 跳到第一行 |
| `G`（Shift + g） | 跳到最後一行 |
| `:50` | 跳到第 50 行 |

## 搜尋與取代

| 操作 | 說明 |
|---|---|
| `/keyword` | 向下搜尋，`n` 下一個、`N` 上一個 |
| `:%s/old/new/g` | 全文把 `old` 取代為 `new` |

## 刪除、複製、復原

| 操作 | 說明 |
|---|---|
| `dd` | 刪除整行 |
| `yy` 然後 `p` | 複製整行並貼上 |
| `u` | 復原上一步 |
